# Magpie iOS App

Compliant SwiftUI + WKWebView iOS shell with an embedded local HTTP reverse-proxy gateway (`127.0.0.1:3425`) supporting bidirectional translation across OpenAI Chat/Responses, Anthropic Messages, and Gemini v1beta, plus the bundled `www/index.html` control panel.

## Build
Built via XcodeGen + `xcodebuild` on `macos-14` GitHub Actions (`build-ipa.yml`) producing `Magpie-unsigned.ipa`.
